# Grade Calculator

Calculadora de médias escolares no browser: disciplinas, pesos e resultado instantâneo.

## Stack

- Vite
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix), React Router, TanStack Query, jsPDF

## Correr localmente

```bash
npm install && npm run dev
```
